# Feedback

Feedback is recorded verbatim first, interpreted second.

Template headings: `Source` (with `Verbatim` and `Details` beneath it), `Discussion settled details`, `Notes`. Write them with `pt section set <id> "Verbatim"` (exact, case-sensitive, no leading `#`).

## Record feedback

1. Create a `feedback` item and put the exact words under `### Verbatim` before writing anything else. Trim only to fit the medium; never paraphrase in this section.
2. Under `### Details`, note source, context, and what the words leave open.
3. Derive the work: one item per actionable piece, linked back to the feedback item with `--related-to`. Interpretation lives in those items, so the verbatim text stays the single record of what was actually said.
4. Record what the discussion with the source settled under `## Discussion settled details`.
5. Close the feedback item when every derived item exists and is linked. While interpretation is still undecided, leave it `open` and write the open question under `## Discussion settled details`.

## Done

`Verbatim` holds the exact words, derived items exist and are linked with `relatedTo`, and the feedback item is `closed` or carries the open interpretation under `Discussion settled details`.
