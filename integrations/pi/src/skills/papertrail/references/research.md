# Research

Research is reading and reporting. No code changes.

Template headings: `Question`, `Findings`, `Conclusion`, `Notes`. `pt section set <id> "Findings"` matches the exact, case-sensitive heading text without the leading `#`.

## Run research

1. Create a `research` item whose `## Question` states what reading must settle.
2. Read the sources; keep citations or paths with each finding under `## Findings`.
3. Write the answer under `## Conclusion` in a form that decides the question, naming what each finding contributes.
4. Where the conclusion implies work, create items and link them to the research item.
5. Close the research item once the conclusion is written. If code changed during research, the item type was wrong: record that under `Notes` and continue in a `task` or `spike`.

## Done

`Conclusion` answers the question with sourced findings, implied work is itemized and linked, and the item is `closed`. A `mode: hitl` research item moves to `review` until the human accepts the conclusion.
